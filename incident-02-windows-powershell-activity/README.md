# Incident 02 – Suspicious PowerShell Activity on Windows Endpoint

## Overview
This incident documents the detection and analysis of suspicious PowerShell activity
observed on a Windows endpoint. The behavior suggested potential post-exploitation
activity or malicious script execution.

## Environment
- OS: Windows
- Endpoint type: Corporate workstation
- Detection source: Endpoint telemetry / SOC monitoring
- Attack surface: PowerShell execution

## Incident Timeline (High-Level)
- Detection of abnormal PowerShell execution
- Triage and validation of alert
- Deep investigation of command execution and context
- Assessment of impact and attacker intent
- Response and remediation actions
